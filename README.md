Данный проект посвящен решению задачи классификации — прогнозированию оттока клиентов (churn). Основная цель — на основе исторических данных о клиентах телекоммуникационной компании построить модель, которая сможет с высокой точностью предсказать, какие клиенты с наибольшей вероятностью прекратят пользоваться услугами компании.

**Метрика качества:** ROC-AUC.

## Описание набора данных

Данные представлены тремя файлами в формате CSV:
*   `train.csv` — обучающая выборка с целевой переменной `Churn`.
*   `test.csv` — тестовая выборка (без целевой переменной).
*   `submission.csv` — пример файла для загрузки решения.

Исходный датасет содержит информацию о 5282 клиентах и включает в себя следующие признаки:

*   **Числовые признаки:**
    *   `ClientPeriod` — срок обслуживания клиента (в месяцах).
    *   `MonthlySpending` — ежемесячные расходы клиента.
    *   `TotalSpent` — общая сумма, потраченная клиентом.
*   **Категориальные признаки:** (Пол, наличие партнера, детей, тип интернета, способ оплаты и т.д.)
*   **Целевая переменная:**
    *   `Churn` — факт оттока (1 — клиент ушел, 0 — клиент остался).


## Основные этапы работы

Проект включает в себя все ключевые шаги классического пайплайна машинного обучения:

### 1. Первичный анализ данных (EDA)
*   Проверка данных на наличие пропусков и дубликатов. Было обнаружено 28 дубликатов, которые были удалены.
*   Анализ пропусков в признаке `TotalSpent`. Выявлено, что пропуски соответствуют новым клиентам (`ClientPeriod` = 0), которые еще ничего не потратили. Пропуски были заполнены нулями.

### 2. Исследовательский анализ и визуализация
*   **Целевая переменная:** Выявлен сильный дисбаланс классов (клиенты, которые не ушли, преобладают).
*   **Числовые признаки:**
    *   Обнаружена высокая корреляция между `ClientPeriod` и `TotalSpent`. Вероятно, `TotalSpent` вычисляется как произведение периода на среднемесячный платеж.
    *   Выявлено, что клиенты с высокими ежемесячными расходами (`MonthlySpending`) чаще уходят на ранних этапах.
    *   Для признака `TotalSpent` успешно применено преобразование Бокса-Кокса (`PowerTransformer`), чтобы сделать его распределение более похожим на нормальное.
*   **Категориальные признаки:**
    *   Проведен детальный анализ влияния каждого признака на целевую переменную.
    *   **Ключевые наблюдения:**
        *   Клиенты с опцией "Fiber optic" уходят чаще, что может указывать на проблемы с качеством услуги.
        *   Наличие контракта на длительный срок ("One year", "Two year") значительно снижает вероятность оттока.
        *   Способ оплаты "Electronic check" ассоциируется с самым высоким уровнем оттока.
        *   Некоторые признаки, такие как `Sex` (пол), были признаны неинформативными и впоследствии удалены для уменьшения шума.
    *   Проведен анализ сегментов пользователей:
        *   Клиенты, пользующиеся только телефоном, уходят реже, чем клиенты с интернетом.
        *   Клиенты, пользующиеся и телефоном, и интернетом, уходят чаще всего.

### 3. Предобработка данных и Feature Engineering
*   Удалены дубликаты и обработаны пропуски.
*   Числовые признаки (`MonthlySpending`, `TotalSpent`, `ClientPeriod`) отмасштабированы с помощью `StandardScaler`.
*   Категориальные признаки преобразованы в числовой формат.
*   Проведен отбор признаков: на основе корреляционного анализа удалены признаки, вносящие шум (`Sex`, `HasMultiplePhoneNumbers`, `HasOnlineTV`, `HasMovieSubscription`).
*   Данные разделены на обучающую и валидационную выборки (70/30) со стратификацией по целевой переменной.

### 4. Моделирование и оценка
*   На данных применено PCA для визуализации и подтверждения возможности разделения классов.
*   Обучен и оценен целый ряд моделей классификации, включая:
    *   Logistic Regression
    *   Random Forest
    *   Decision Tree
    *   K-Neighbors Classifier
    *   CatBoost
    *   Stacking и обучение мета-модели
*   Для оценки качества использовалась метрика **ROC-AUC**.

## Ключевые выводы и результаты
Лучшее качество достигнуто на модели CatBoostClassifier: ROC AUC 0.8542
